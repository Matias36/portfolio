¿Qué puedo hacer?

Los servicios que ofrezco son variados:

Realizo logotipos, flyers, carteles, entre otras par anegocios ya establecidos o para nuevos emprendimientos.

¿Querés que tu marca tenga una identidad visual única y coherente? Puedo ayudarte a crear un branding completo que refleje la esencia de tu negocio y conecte con tu tu público objetivo.

Puedo crear ilustraciones personalizadas para libros, revistas, cómics, portadas de álbumes, entre otros. Mi estilo es versátil y puedo adaptarme a diferentes géneros y temáticas.

Puedo realizar animaciones 2D que reflejen la personalidad de tu marca y/o proyecto. Tambien motion graphics para videos explicativos, presentaciones, publicidad y más.

Hago edición general para videos, para redes sociales, presentaciones, videos largos, cortos, entre otros, te ayudo a que tu contenido sea más atractivo y profesional.

Realizo edición de audio para que tus proyectos tengan un sonido claro, límpio y de calidad. Puedo limpiar ruidos, ajustar niveles, agregar efectos y más.

Creo modelos 3D para videojuegos, animaciones simples, esculturas digitales, modelos low poly, estilizados, entre otras.

Diseño webs, landing pages, tiendas online, portfolios, o la idea que quieras plantear. Te ayudo a crear una web interactiva y entretenida para el usuario que te querés dirigir.

Puedo realizar visuales interactivas para instalaciones, eventos o presentaciones. La tecnología que utilizo es p5.js con lenguaje de programación JavaScript, lo que me permite crear experiencias interactivas y personalizadas para el usuario.

Puedo utilizar Arduino o Esp32 para crear proyectos interactivos utilizando sensores, luces, cámaras, entre otros componentes eléctronicos.
